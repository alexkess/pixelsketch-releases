# PixelSketch — Releases

Update feed and downloads for **PixelSketch**, the macOS app by
[Kess Media](https://kess.media) that turns artwork into draw-on animation for
Final Cut Pro and VideoScribe. The app updates itself via
[Sparkle](https://sparkle-project.org) from the `appcast.xml` in this repo;
zips are attached to GitHub Releases.

Requires macOS 13 or later on Apple Silicon. Unzip, move `PixelSketch.app` to
Applications, and later updates arrive through **PixelSketch ▸ Check for Updates…**.

Source code is not published here.
